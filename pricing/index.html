These entitlements apply to ViewSieve. Pro and Max subscriptions renew automatically; annual plans are billed yearly. Chrome sync requires verified Max access and explicit opt-in.

All three platforms share this device’s allowance, reset each local calendar day. Successfully hiding keyword, author, promotional or specific content matches, and successfully auto-skipping YouTube ads, uses allowance. Failed attempts do not. Navigation, comment-area and layout changes alone do not count.

Rules include keywords, blocked authors and allowlists. Disabled rules count; a cross-platform rule counts once. Max has no commercial local-rule limit, while Chrome configuration sync has an 80 KiB capacity.
