帮助与联系

支持哪些平台？

桌面 Chrome 中的 YouTube、Instagram 和 TikTok。各平台提供对应的内容与页面净化选项，按需开启并单独授权。

添加屏蔽规则后会发生什么？

匹配内容立即隐藏，快捷添加后提供 3 秒撤销；后续命中不再显示内容或原因占位。TikTok 推荐流自动跳过命中项，保留原生上下切换。

会隐藏我主动打开的视频吗？

明确主动打开的主内容有观看保护，周边推荐继续过滤。进入通用推荐流或后续翻页不会自动获得保护。

自动跳过能移除所有广告吗？

不能。它使用 YouTube 已可用的原生跳过按钮，不跳过不可跳广告，不承诺处理口播或服务端拼接广告。内容广告过滤依据明确推广标记，不仅凭品牌名或购物词识别。

每日净化额度如何计算？

成功的内容净化和 YouTube 广告自动跳过共享当前 Chrome 配置文件的每日额度，按本地自然日重置，失败不计。用完后停止新的净化，原生浏览和手动跳过广告仍可使用。

Max 可以同步什么？

平台净化选项、布局、关键词、作者名单、规则启停和顺序。默认关闭，需同意后开启，并使用同一 Chrome 同步账号与扩展 ID，容量为 80 KiB。授权、暂停、用量和支付凭据不参与同步；冲突时由你选择保留版本。

现在可以订阅吗？

正式订阅请从商店安装版 ViewSieve 的“套餐与用量”进入 ExtPay / Stripe，官网不直接收款。Free 提供额度内内容净化；Pro、Max 增加页面净化，Max 另含可选 Chrome 配置同步。ViewSieve 已在 Chrome 商店上架。本地加载已解压副本会使用 ExtPay 测试支付，不代表正式收款。
