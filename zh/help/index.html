开始使用

  1. 当前为受限分发版本，尚无公开商店安装链接。取得可信安装包后，解压到固定目录。
  2. 打开 chrome://extensions，启用开发者模式，选择「加载已解压的扩展程序」。
  3. 选择包含 manifest.json 的目录。Chrome 安装名称保留为 ViewSieve Enhanced。
  4. 打开插件，启用并授权 YouTube，再添加关键词或频道规则。升级后请重新加载扩展，并刷新旧标签页。

常见问题

目前支持哪些平台？

当前版本支持桌面 Chrome 中的 YouTube。Instagram 和 TikTok 仍在规划中。

会屏蔽我主动打开的视频吗？

主动打开的主视频会保留，周边推荐继续按规则过滤。已折叠的卡片也可以单次展开。

能完全移除广告吗？

不能。自动跳过只会点击已可用的原生跳过按钮；不可跳广告、口播及服务端拼接广告不在本功能承诺范围。

现在需要付费吗？

当前版本免费，并保留已有功能。Free / Pro 是未来套餐规划，尚未开放购买或试用。

过滤或跳过没有生效？

检查总开关、YouTube 授权和暂停状态；确认只启用一个版本。升级后刷新页面。广告需要出现可操作的原生跳过按钮；后台标签页、遮挡或平台改版可能使功能不可用。插件弹窗中可查看诊断。
