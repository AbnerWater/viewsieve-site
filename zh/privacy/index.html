隐私与数据

内容净化在本机执行

在已授权的支持页面，扩展使用实际可用的标题、说明、标签和可靠作者标识匹配规则，不通过补抓隐藏详情完成匹配，不读取私信或评论正文。页面正文与账号名单不发送到 ViewSieve、ExtPay 或 Stripe。

本地配置与必要计量

规则、作者名单、平台偏好及恢复快照存放在扩展本地存储。每日净化计量、订阅核实缓存、网站实际授权、总开关与暂停是本机数据，不参与配置云同步。必要额度计量不等同于使用情况分析；本功能没有页面遥测或广告跟踪。

可选的 Chrome 配置同步

仅 Max 可主动开启，默认关闭。明确同意后，将平台净化选项、布局、关键词和作者名单等配置交给 Chrome 同步，可能反映个人偏好。传输由 Chrome 及 Google 同步设置管理，同一账号及扩展 ID 是跨设备前提；容量为 80 KiB。配置不会发送给支付服务。

Google 隐私政策 ↗

关闭与删除同步

关闭同步停止本机后续共享，保留本机和共享副本。删除共享副本需单独确认；其他设备收到删除标记后暂停同步并保留其本机配置。离线设备的送达无法在扩展内确认，未收到标记的设备可能写回旧数据。冲突配置由用户比较选择，不按时间戳静默覆盖。

支付登录与网站数据

扩展集成 ExtPay，并由其关联 Stripe 处理订阅；购买尚未开放。用户主动进行订阅登录或状态恢复时，SDK 与服务方交换账户/权益信息并保存必要的登录标识，其 SDK 可能使用 Chrome 同步存储。支付登录与产品配置同步独立，删除配置副本不会删除支付登录。扩展不把规则、账号名单、页面内容或净化用量交给支付服务。

ExtensionPay 服务与隐私说明 ↗

权限与本机诊断

storage 用于保存配置，scripting 用于已授权网站，alarms 用于状态维护。debugger 权限用于在已确认的前台 YouTube 观看页点击可用原生跳过按钮，Chrome 可能显示调试提示。页面诊断只展示有限运行状态，不含规则、正文或账号信息，不自动上传。

官网与联系

官网由 GitHub Pages 托管，未加入分析、广告像素、支付 SDK 或产品账户系统。字体和图片随站提供，交互演示仅保存在内存中。GitHub 为提供服务处理请求信息。支持邮箱由 Outlook.com 承载，你主动发送的邮件用于处理支持或隐私请求；请仅提交必要信息。
