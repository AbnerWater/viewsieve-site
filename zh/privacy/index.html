范围与负责人

ViewSieve 由个人开发者 AbnerWater 提供。本文适用于扩展、官网及支持渠道，自 2026 年 9 月 21 日更新。隐私请求请联系 abnerwater@outlook.com。本说明涵盖本机处理的数据，不将“留在本机”等同于“不处理数据”。

页面内容、作者与浏览上下文

在用户单独授权的 YouTube、Instagram、TikTok 页面上，扩展使用实际可见的标题、说明、标签、内容链接、可靠作者 ID 或主页地址、平台广告和 AI 标记，以及媒体状态执行过滤。当前支持页面的 URL、内容身份、点击或键盘导航、滚动和可视状态仅用于匹配、主动观看保护、正确切换、计量及页面诊断；不读取 Chrome 历史数据库，不建立跨网站浏览档案，不记录连续点击、按键或鼠标轨迹，不读取私信或评论正文，也不补抓隐藏详情。页面匹配在本机完成。

本地配置与必要计量

关键词、作者屏蔽及白名单、平台偏好、语言和恢复快照保存在本地。每日成功净化数量及去重摘要、成功时间和相关规则标识用于执行额度；摘要不是页面正文，仍属于本地内容相关数据，不作为匿名统计上传。计量在下一次有效跨日访问时更新，不做跨设备同步。权限状态、暂停、总开关及权益缓存也保留在本机。没有广告跟踪或页面分析上报。

可选的 Chrome 配置同步

仅 Max 可主动开启，默认关闭。明确同意后，将平台净化选项、布局、关键词和作者名单交给 Chrome storage.sync；这些内容可能反映个人偏好。Google 按 Chrome 及账号同步设置处理和传输，同一账号及扩展 ID 是跨设备前提，配置预算为 80 KiB。页面正文、每日用量和支付权益不属于产品配置同步。规则和作者名单不会发送给 ExtPay 或 Stripe。

Google 隐私政策 ↗

关闭与删除配置同步

关闭同步停止本机后续共享，但保留本机和共享副本。删除共享副本需另行确认；其他设备收到删除标记后暂停同步并保留本机配置。离线设备的送达无法在扩展内确认，未收到标记的设备可能写回旧数据。冲突由用户比较选择，不静默覆盖。删除产品配置副本不删除 ExtPay 登录记录。

订阅、身份及支付凭据

ExtPay / Stripe 处理购买和登录恢复，使用付款邮箱、所选套餐、支付与订阅状态、金额、周期和日期。扩展内的 ExtPay SDK 保存支付访问令牌、安装日期和服务端用户记录（可能含邮箱和订阅状态）；优先使用 Chrome 同步存储，不可用时回退本地。这一 SDK 行为独立于 Max 配置同步，可用于恢复支付登录。后台通过 HTTPS 核实权益，前台页面只获得脱敏套餐信息。扩展不读取银行卡号、CVC、密码或完整付款表单；敏感卡片信息由托管 Stripe 页面处理。启动、支付返回、主动刷新及每小时核实权益，不向支付服务传送规则、作者名单、页面内容或净化用量。

ExtensionPay 服务与数据说明 ↗

支付服务的设备与网络数据

用户打开托管结账或管理页面时，ExtPay / Stripe 会按其政策处理邮箱、交易信息、账单地址以及网络请求中的 IP、设备和粗略地区等信息，用于结账、税费、身份恢复、防欺诈及服务安全。ViewSieve 不请求 GPS 或 Chrome 地理位置权限，也不将位置用于内容过滤或广告。支付平台的留存与删除遵循其政策及适用的财务要求。

Stripe 隐私政策 ↗

权限与本机诊断

storage 用于本地数据、SDK 登录及经同意的配置同步；scripting 只在用户授权的网站运行随包提供的脚本；alarms 用于暂停恢复、订阅核实和同步维护。debugger 仅在前台已授权 YouTube 普通观看页对可用原生跳过广告按钮发送鼠标输入，完成、取消或超时后解除；不通过该权限记录网络流量。页面诊断仅由用户触发，展示有限状态，不包含页面正文、规则、账号或付款凭据，不自动上传。

公开反馈、邮箱与官网

官网及官方 Issues 由 GitHub 提供服务。官网不加入分析、广告像素、支付 SDK 或产品账号系统，演示只在内存运行。GitHub 会处理请求 IP 等服务数据。提交 Issue 时，用户自行提供的 GitHub 用户名、问题内容及附件公开可见；扩展不会自动填入页面内容或配置。不要提交规则导出、个人账号、登录链接、凭据或付款资料。付款、隐私和安全问题请私密发送至 abnerwater@outlook.com，邮件由 Outlook.com 承载，仅用于处理请求；扩展不能访问用户邮箱或聊天。

GitHub 隐私声明 ↗

留存与用户控制

规则和设置保留至用户修改、清除扩展数据或卸载；本地恢复快照可能仍含旧规则。运行中的媒体与导航状态只用于当前会话，每日去重记录在下次有效跨日更新时替换。SDK 登录及缓存、Chrome 共享副本可能在重装时恢复，卸载不等于删除云端副本或取消订阅。用户可关闭网站权限、暂停过滤、单独删除共享配置，并通过托管门户取消续费。支付、支持资料的访问、更正或删除请求可发送到支持邮箱；提供处理请求所需最少信息。公开 Issue 可自行编辑或关闭，关闭不等于删除公开记录；删除附件或其他副本需联系 GitHub。依法必须保留的交易记录可能无法立即删除。

用途限制与安全

ViewSieve 遵守 Chrome Web Store 用户数据政策及 Limited Use 要求。数据仅用于用户所请求的净化、偏好恢复、订阅及支持功能，不出售数据，不用于个性化广告、信用评估或贷款；只向实现这些功能必需的服务商或在法律要求、安全调查等允许情形下传递。不会人工查看用户的本地浏览内容；人工支持只处理用户主动提供的具体资料或适用政策允许的情况。服务请求使用 HTTPS，不声称任何系统绝对安全。重大变化将更新本说明。
