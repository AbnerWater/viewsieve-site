隐私政策

主体：AbnerWater生效日期：2026-09-18

当前插件：在设备上处理

你授权 YouTube 后，插件读取受支持区域中已提供的标题、频道标识和可见字段来判断规则，不额外请求隐藏详情，不检查私信，也不申请完整浏览历史或 Cookie 权限。

本地配置

规则、频道名单、语言、模块设置、暂停状态和恢复配置保存在 Chrome 本地扩展存储。当前版本没有产品账号、云同步、使用统计或浏览内容上传服务。数据保留在设备上，直至修改或移除；卸载会移除扩展存储。浏览器和系统备份不受净览控制。

自动跳过与权限

增强版包含 debugger 权限，该权限在技术上具有广泛的网页调试能力。本项目实现仅用于当前前台、已授权的 YouTube 观看页中，向已确认可用的原生 Skip 按钮发送可信输入，Chrome 可能显示调试提示。过滤还使用 storage、scripting 和 alarms。你可以关闭跳过、暂停插件或撤销 YouTube 授权。此功能不修改正片进度、倍速或音量。

诊断

播放器诊断仅在本地展示有限的版本、模式和失败阶段，不自动上传，也不包含规则、视频标题和账号信息。支持报告只应包含你主动选择分享的信息。

本网站

本静态网站由 GitHub Pages 托管。净览不加入遥测、广告像素、支付 SDK、账号、邮箱收集表单或非必要 Cookie。字体和图片由网站本身提供，交互演示选择仅保留在内存中。GitHub 为提供和保护其服务会处理 IP 地址等请求信息，其处理及保留遵循 GitHub 隐私声明。

GitHub 隐私声明

支持联系

支持由个人开发者 AbnerWater 通过 Microsoft Outlook.com 邮箱 abnerwater@outlook.com 提供，网站没有反馈表单。来信地址、正文和附件用于回复及处理问题，仅在支持需要和适用法律要求的必要期限内保留。你可以向同一邮箱申请访问、更正或删除信息；法定保留义务可能限制删除。Microsoft 按其隐私声明处理邮件数据。

Microsoft 隐私声明

未来服务与控制权

支付、云同步和账号尚未启用，引入前需要更新数据处理说明。你可以控制本地规则及权限；Chrome 和 YouTube 自身仍适用各自的政策。
