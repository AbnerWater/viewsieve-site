Getting started

  1. There is no public store listing yet. If you have an authorized package, extract it to a permanent directory.
  2. Open chrome://extensions, enable Developer mode and choose “Load unpacked”.
  3. Select the folder containing manifest.json. Chrome retains the installation name ViewSieve Enhanced.
  4. Open the extension, enable and authorize YouTube, then add keyword or channel rules. After upgrading, reload the extension and refresh old tabs.

Why these permissions?

YouTube
Optional access to read visible fields and apply filters on supported pages. You can revoke it.
storage · scripting · alarms
Save local settings, enable page processing and resume temporary pauses.
debugger
An installation-level permission with broad debugging capability. The implementation uses it for trusted clicks on available Skip buttons in the foreground watch page. Chrome may show a debugging notice. Auto-skip can be switched off.

Common questions

Which platforms work today?

The current build supports YouTube in desktop Chrome. Instagram and TikTok are on the roadmap.

What about a video I open myself?

Your actively opened main video stays visible. Surrounding recommendations still follow your rules, and you can show a filtered card once.

Will this remove every ad?

No. Auto-skip clicks a native Skip button once it is available. Unskippable ads, spoken sponsorships and server-stitched ads are not covered by that promise.

Do I need to pay?

The current build is free and retains its existing features. Free / Pro describes future plans; purchasing and trial enrollment are not available.

Filtering or skipping is not working?

Check the global switch, YouTube permission and pause status; keep only one edition enabled. Refresh after an upgrade. Auto-skip needs an actionable native button. Background tabs, obstructions or platform changes may prevent it. Open diagnostics in the extension popup for details.
