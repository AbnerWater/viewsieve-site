# ViewSieve website & support

[Website](https://abnerwater.github.io/viewsieve-site/) · [Report an issue](https://github.com/AbnerWater/viewsieve-site/issues/new/choose) · [Privacy](https://abnerwater.github.io/viewsieve-site/privacy/)

ViewSieve helps filter unwanted content on YouTube, Instagram and TikTok. This public repository hosts the generated website and official feedback templates, not the extension source code.

## Get help / 获取支持

Use **Issues** for bugs and feature suggestions, in English or 简体中文. Include your extension version, Chrome version, platform and steps to reproduce. Use fictional examples and redact screenshots. Do not post passwords, login links, payment identifiers, private page content, rule exports or personal account details. Issues and attachments are public.

问题与功能建议请使用 Issues，支持中英文。提供扩展版本、Chrome 版本、平台和复现步骤即可。请使用虚构示例并对截图脱敏；不要公开密码、登录链接、支付标识、私密正文、规则导出或个人账号信息。所有问题与附件公开可见。

For billing, privacy requests or security reports, email **abnerwater@outlook.com**. Do not send card numbers, passwords or authentication tokens. No response-time guarantee is implied. / 付款、隐私或安全问题请使用上述私密邮箱，不要提供卡号、密码或凭据。

Subscriptions are managed through the extension's Plan & usage page. This repository and website do not accept payments. Current prices and terms are on the website.
